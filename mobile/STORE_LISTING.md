## 설명 (긴 설명)
```

● 버튼 하나로 녹음
수업 중이나 수업 직후 "3번 김민수, 토론에서 근거를 세 가지 들어 반론을 폈음"처럼 말하기만 하세요. 화면을 꺼도 계속 녹음됩니다.

● 컴퓨터로 자동 전송
아이폰은 iCloud로, 갤럭시·아이폰 모두 선생님 본인의 구글 드라이브로 컴퓨터의 쓰담 프로그램에 자동 전달됩니다. 파일을 옮기거나 이름을 붙일 필요가 없습니다.

● 학생별 정리와 생기부 초안 (컴퓨터용 쓰담)
컴퓨터의 쓰담이 녹음을 컴퓨터 안에서 글자로 바꾸고(외부 전송 없음), 학생 이름이 나온 곳을 기준으로 학생별 관찰기록으로 나눕니다. 학기말에는 교과 세특, 행동특성 및 종합의견, 자율·자치·동아리·진로활동 초안을 만들고 NEIS 바이트도 계산해 줍니다.

● 학기말까지 안전하게 보관
녹음은 선생님이 지우기 전까지 자동으로 지워지지 않습니다.

● 개인정보
개발자 서버가 없습니다. 녹음과 기록은 선생님의 기기와 본인 계정의 iCloud·구글 드라이브에만 저장됩니다. 회원가입·광고·분석 도구가 없습니다.

컴퓨터용 쓰담(맥·윈도우)은 https://hanseolhui.github.io/sseudam/ 에서 무료로 받을 수 있습니다.
```

## 등록 순서

### 아이폰 (App Store Connect)
1. Xcode → 설정 → Accounts에 Apple ID 로그인 (개발자 계정)
2. 개발자가 빌드하면 번들 ID `kr.sseudam.app`과 iCloud 컨테이너가 자동 등록됨
3. [App Store Connect](https://appstoreconnect.apple.com) → 앱 → **+ 새로운 앱** → iOS · 이름 '쓰담 – 말로 쓰는 학생 관찰 기록' · 기본 언어 한국어 · 번들 ID `kr.sseudam.app` · SKU `sseudam-ios`
4. 개발자가 TestFlight로 업로드 → TestFlight 탭에서 내부 테스터(본인) 추가 → 아이폰 TestFlight 앱으로 설치
5. 스크린샷(6.9", 6.5") · 위 설명 · 개인정보 설문 → 심사 제출

### 안드로이드 (Play Console)
1. [Play Console](https://play.google.com/console) → **앱 만들기** → 이름 '쓰담 – 말로 쓰는 학생 관찰 기록' · 앱 · 무료
2. 테스트 → **내부 테스트** → 새 버전 → `Sseudam-Android.aab` 업로드 (Play 앱 서명 사용)
3. 테스터 이메일 추가 → 링크로 설치
4. 스토어 등록정보 · 데이터 보안 · 콘텐츠 등급 · 타겟층(성인/교사) 작성 → 프로덕션 출시

> 안드로이드 업로드 키: `~/.sseudam/upload-keystore.jks` + `~/.sseudam/keystore.properties` — **반드시 따로 백업**하세요. 잃어버리면 Play 지원팀에 키 재설정을 요청해야 합니다.
